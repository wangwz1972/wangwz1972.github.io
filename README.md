# A股市场三维演化 · 三维数据可视化作品

> 我把整个 A 股市场，写进了一张会呼吸的星云里。

**在线体验**：https://wangwz1972.github.io/

## 这是什么

一件可交互的三维数据可视化作品。把 A 股全市场的真实数据，映射进了一个三维空间。每一粒光点都不是随机生成的——它们背后，都对应着一个真实存在的东西。

它会动，而且动得有规律；颜色也不只有一种含义；相近的颜色会聚在一起，又散开。

至于具体是什么、为什么这样排列，我把它留给你去猜。去亲手拖动、缩放，慢慢找。

## 技术栈

- 三维渲染：Three.js
- 数据：A 股全市场真实数据
- 交互：可拖拽、缩放、旋转
